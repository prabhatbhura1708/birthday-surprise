# Birthday Surprise — Akanksha

A small interactive birthday experience made for Akanksha Dewangan.

## Free deployment

This is a static HTML/CSS/JS site and can be hosted for free with GitHub Pages.

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The site will be available at:

`https://prabhatbhura1708.github.io/birthday-surprise/`

## Music

The experience uses the YouTube video ID from the supplied link and starts the player after the visitor interacts with the page. This avoids trying to download or redistribute the audio file.
